# АО «Портал» — голосовые ИИ-агенты (frontend)

React + Vite. Консоль для разговоров с голосовыми ИИ-агентами LiveKit.

**Бэкенда нет.** Приложение не знает ни про один API, кроме эндпоинта токенов
LiveKit, который поставляется вместе с ним. FastAPI из `backend/` этому проекту не
нужен: ни в разработке, ни в продакшене.

## Запуск

```bash
npm install
cp .env.example .env      # заполнить LIVEKIT_* — см. ниже
npm run dev               # http://localhost:5173
npm run build
npm run lint
npm test
```

## Как устроен звонок

1. Браузер спрашивает `POST /api/livekit/token` и получает грант.
2. Подключается к комнате по этому гранту и публикует микрофон.
3. Слушает звук агента и читает его расшифровку.

Всё остальное — распознавание речи, определение turn'ов, рассуждение, инструменты и
перебивание — происходит на стороне агента. В частности, перебивание не требует от
браузера ничего: агент замолкает, как только заговорил человек.

## Эндпоинт токенов

Он поставляется вместе с приложением и разворачивается как функция Vercel:

| Среда | Что отвечает |
| --- | --- |
| Продакшен | `api/livekit/token.js` (Vercel обслуживает каталог `api/` как функции) |
| Разработка | тот же обработчик, смонтированный плагином `server/viteLiveKitToken.js` |

Правила выпуска гранта — в `server/livekitToken.js`. Существенно вот что:

- **Комнату называет сервер.** Грант выдаётся на одну комнату, и её имя строит сервер.
  Браузер не может указать имя комнаты, а значит не может попасть в чужой звонок.
- **Агента тоже называет сервер** — из `LIVEKIT_AGENT_NAME`. Разрешить браузеру выбирать
  агента значило бы выдать секрет другим путём.
- Браузер присылает только `participant_name` и, по желанию, контекст звонка.

```http
POST /api/livekit/token
  { "participant_name": "Оператор" }
-> 201
  { "server_url": "wss://…", "participant_token": "…", "room": "portal-…", "identity": "operator-…" }
```

Схема — стандартная для LiveKit, поэтому тот же эндпоинт подходит любому клиентскому
SDK. Старые имена полей (`token`, `url`) тоже понимаются.

### Переменные окружения

Секреты читаются **только на сервере** и никогда не попадают в сборку.

| Переменная | Обязательна | Назначение |
| --- | --- | --- |
| `LIVEKIT_API_KEY` | да | Ключ LiveKit |
| `LIVEKIT_API_SECRET` | да | Секрет LiveKit |
| `LIVEKIT_URL` | да | `wss://…` |
| `LIVEKIT_AGENT_NAME` | нет | Имя агента для dispatch. Без него комната откроется, но отвечать в ней некому |
| `LIVEKIT_AGENT_METADATA` | нет | Метаданные, передаваемые агенту |
| `LIVEKIT_ROOM_PREFIX` | нет | Префикс имён комнат (по умолчанию `portal`) |
| `LIVEKIT_TOKEN_TTL` | нет | Срок жизни гранта (по умолчанию `10m`) |
| `VITE_LIVEKIT_TOKEN_ENDPOINT` | нет | Эндпоинт на другом хосте. Браузер пойдёт к нему напрямую, поэтому сервис обязан разрешать CORS для этого сайта |
| `VITE_GOOGLE_CLIENT_ID` | нет | Остался от прежней авторизации; **вход удалён**, значение больше ничего не включает |

## Что где хранится

Всё живёт в `localStorage` этого браузера и никуда не отправляется:

- **Подключение** — адрес эндпоинта, имя участника, необязательный готовый токен.
- **Агент** — название, роль, назначение. Это подпись для интерфейса, а не настройка
  агента: кто отвечает на линии, решает `LIVEKIT_AGENT_NAME`.
- **История звонков**, **контакты**, **сценарии** — локальные записи.

Ничего из этого не общее для других операторов и не переживёт очистку данных сайта.
Это осознанное ограничение: без своего сервера у приложения нет иного места, где
можно было бы хранить состояние.

### Сценарии

Проверка допуска выполняется по-настоящему: учитываются статус сценария, дата в
карточке контакта, согласие на звонки и удобное время. Кнопка «поставить в очередь»
**не звонит** — телефонии здесь нет, и приложение не делает вид, что она есть. Она
записывает задачу в историю, и начать разговор нужно вручную на главной. По расписанию
ничего не выполняется: для этого нужен процесс, который не спит.

## Маршруты

| Путь | Экран |
| --- | --- |
| `/` | Сайт |
| `/app/dashboard` | Консоль: разговор, расшифровка, итоги |
| `/app/calls` | История звонков (локальная) |
| `/app/contacts` | Контакты (локальные) |
| `/app/workflows` | Сценарии (локальные) |
| `/app/settings` | Настройки оформления и подключения |
| `/?call=1&name=Анна` | Экран звонка для телефона: приглашает в комнату, созданную для этого гранта |

```bash
npm run dev      # токен-эндпоинт и приложение на одном origin, CORS не нужен

```
